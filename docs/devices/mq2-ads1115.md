# MQ-2 + ADS1115 — เซนเซอร์ก๊าซติดไฟ (legacy)

[← กลับสารบัญ](../README.md)

> **สถานะ: ทางเลือก** — MQ-2 คือเซนเซอร์เดิมจากยุค Arduino UNO Q
> เอกสารนี้อธิบายวิธีย้ายมาใช้บน Pi 5 **และเหตุผลที่อาจไม่ควรย้ายมาเลย**

---

## 1. ⚠️ ตัดสินใจก่อน: ยังต้องใช้ MQ-2 อยู่ไหม

Raspberry Pi 5 **ไม่มี ADC ในตัว** การจะใช้ MQ-2 ต่อจึงต้องเพิ่มฮาร์ดแวร์และความซับซ้อน
ขณะที่เซนเซอร์ใหม่ทั้งสามตัวครอบคลุมสิ่งที่ MQ-2 เคยตรวจจับได้แทบทั้งหมดแล้ว

| สิ่งที่ MQ-2 ตรวจจับ | เซนเซอร์ใหม่ที่ทำได้ดีกว่า |
|---|---|
| ควัน | **PMS7003** — วัดอนุภาคจริงเป็น µg/m³ ไม่ใช่ค่าประมาณ |
| แอลกอฮอล์ · ตัวทำละลาย | **SGP30** — วัด TVOC โดยเฉพาะ พร้อม baseline compensation |
| ควันจากการทำอาหาร | **PMS7003 + SGP30** ร่วมกัน |
| LPG · มีเทน · โพรเพน | ❌ ไม่มีตัวใหม่ตัวไหนวัดได้ |
| ไฮโดรเจน | SGP30 มีสัญญาณ H₂ ดิบ (แต่ไม่ได้ส่งออกเป็น ppm) |

### ตารางเปรียบเทียบ

| | **เก็บ MQ-2 ไว้** | **ตัด MQ-2 ออก** |
|---|---|---|
| ฮาร์ดแวร์เพิ่ม | ADS1115 + voltage divider + สาย | ไม่มี |
| กระแสเพิ่ม | ~150 mA (ฮีตเตอร์ทำงานตลอด) | 0 |
| ความร้อนในกล่อง | เพิ่มขึ้น กระทบ SCD40 | ไม่มี |
| ความแม่นยำ | ต่ำ — ppm ที่ได้เป็นค่าประมาณหยาบมาก | — |
| การ calibrate | ต้อง burn-in 24–48 ชม. + หา R0 | ไม่ต้อง |
| ประโยชน์ที่ได้เพิ่ม | ตรวจแก๊สหุงต้มรั่วได้ | เสียความสามารถนี้ไป |
| งานฝั่งเว็บ | `gas_ppm` และ `AQI_LEVELS` ใช้ต่อได้เลย | ต้องแก้ `config/sensors.js` |

### 💡 ข้อเสนอแนะ

**ถ้าติดตั้งในห้องนอน/ห้องทำงานที่ไม่มีเตาแก๊ส → ตัด MQ-2 ออก**
เพราะ PMS7003 + SGP30 ให้ข้อมูลที่แม่นกว่าและตีความง่ายกว่ามาก
การเก็บ MQ-2 ไว้ทำให้ต้องเพิ่ม ADS1115, ต้อง calibrate, และเพิ่มความร้อนโดยได้ประโยชน์น้อย

**ถ้าติดตั้งใกล้ครัวที่ใช้แก๊ส LPG → เก็บไว้** เพราะไม่มีเซนเซอร์ใหม่ตัวไหนตรวจแก๊สรั่วได้

> ⚠️ **ถ้าเป้าหมายคือความปลอดภัยจากแก๊สรั่วจริง ๆ ควรใช้เครื่องตรวจแก๊สที่ได้รับการรับรองมาตรฐาน**
> ไม่ใช่ MQ-2 บนโปรเจกต์ DIY — MQ-2 ไม่มีการรับรองด้านความปลอดภัยและอาจไม่แจ้งเตือนเมื่อจำเป็น

**ถ้าตัดสินใจตัดออก:** ต้องแก้ `config/sensors.js` เอา sensor `gas` ออก และปรับ `AQI_LEVELS`
ที่อ้างอิง `THRESHOLDS.gas` → ดู [05-data-schema.md](../05-data-schema.md#4-ขั้นตอนถัดไป-code-changes)

## 2. ถ้าตัดสินใจเก็บ MQ-2 ไว้ — ต้องใช้ ADS1115

### สเปก ADS1115

| รายการ | ค่า |
|---|---|
| ความละเอียด | 16 บิต (มี sign) |
| จำนวนช่อง | 4 (single-ended) หรือ 2 (differential) |
| อัตราการสุ่ม | 8 – 860 SPS (ตั้งได้) |
| แรงดันไฟเลี้ยง | 2.0 – 5.5V |
| กระแส | ~150 µA |
| ที่อยู่ I2C | `0x48` (ADDR→GND) · `0x49` (VDD) · `0x4A` (SDA) · `0x4B` (SCL) |
| PGA (ช่วงวัด) | ±6.144V ถึง ±0.256V |

### ⚠️ ข้อจำกัดสำคัญของ PGA

แม้จะตั้ง PGA เป็น ±6.144V ได้ แต่ **แรงดันที่ขาอินพุตห้ามเกิน VDD + 0.3V**

ถ้าจ่ายไฟ ADS1115 ที่ 3.3V → **อินพุตห้ามเกิน 3.6V**
แต่ MQ-2 ส่งออก 0–5V → **ต้องมี voltage divider เสมอ**

---

## 3. วงจร voltage divider

MQ-2 ใช้ฮีตเตอร์ 5V และ AOUT ส่งออกได้ถึง ~5V ต้องลดลงให้ปลอดภัยสำหรับ ADS1115 ที่ 3.3V

```
MQ-2 AOUT ──┬── R1 (10 kΩ) ──┬── ADS1115 A0
            │                 │
            │              R2 (20 kΩ)
            │                 │
           GND ───────────────┴── GND
```

**อัตราส่วน:**

```
V_out = V_in × R2 / (R1 + R2) = V_in × 20k / 30k = V_in × 0.667

ที่ V_in = 5.0V (สูงสุด)  →  V_out = 3.33V   ✅ ปลอดภัย (< 3.6V)
```

**การคำนวณกลับในโค้ด:**

```
V_จริง = V_ที่ ADS1115 อ่านได้ / 0.667
```

> อัตราส่วน `0.667` และค่า R1, R2 **ต้องอยู่ในไฟล์ config** ไม่ใช่เขียนตรงในโค้ด
> เพราะถ้าเปลี่ยนตัวต้านทานแล้วลืมแก้โค้ด ค่าที่ได้จะผิดโดยไม่มีสัญญาณเตือน

**ใช้ตัวต้านทานความคลาดเคลื่อน 1%** — ตัวต้านทาน 5% ทำให้เกิดความผิดพลาดเพิ่มถึง ±10%
ซึ่งมากกว่าความคลาดเคลื่อนของ ADC เองมาก

### PGA ที่ควรตั้ง

หลังผ่าน divider สัญญาณสูงสุด 3.33V → ตั้ง PGA เป็น **±4.096V**
(ไม่ใช่ ±6.144V ซึ่งจะเสียความละเอียดไปโดยเปล่าประโยชน์)

## 4. การต่อสาย

### ADS1115

| ADS1115 | → Pi 5 (ขา) |
|---|---|
| VDD | ขา 1 (3V3) |
| GND | ขา 20 (GND) |
| SCL | ขา 5 (GPIO3) |
| SDA | ขา 3 (GPIO2) |
| ADDR | GND → ได้ที่อยู่ `0x48` |
| A0 | จุดกลางของ voltage divider |
| A1–A3 | ว่าง (เผื่ออนาคต) |

### MQ-2

| MQ-2 | → |
|---|---|
| VCC | ขา 4 (5V) ของ Pi |
| GND | ขา 25 (GND) ของ Pi |
| AOUT | R1 ของ voltage divider |
| DOUT | ไม่ใช้ (เป็นสัญญาณดิจิทัลจากตัวเทียบที่ปรับด้วย potentiometer บนบอร์ด) |

> **ใช้ AOUT เท่านั้น** — DOUT ให้แค่ on/off ตามค่าที่หมุน trimmer ไว้ ซึ่งไม่มีความหมายเชิงปริมาณ
> ถ้าอยากได้สัญญาณเตือนแบบ threshold ให้ทำในซอฟต์แวร์จากค่า AOUT แทน

## 5. การแปลงค่าเป็น ppm

MQ-2 ให้แรงดันที่แปรผันตามความต้านทานของเซนเซอร์ (Rs) ซึ่งเปลี่ยนตามความเข้มข้นของก๊าซ

### ขั้นตอนการคำนวณ

```
1. อ่านค่าดิบจาก ADS1115           → adc
2. V_adc = adc × (PGA / 32767)
3. V_sensor = V_adc / อัตราส่วน divider
4. Rs = R_L × (V_cc − V_sensor) / V_sensor          โดย R_L = 5 kΩ (บนบอร์ดโมดูล)
5. ratio = Rs / R0                                   โดย R0 มาจากการ calibrate
6. ppm = a × ratio^b                                 a, b ต่างกันตามชนิดก๊าซ
```

**ค่าคงที่ `a` และ `b` ประมาณจากกราฟใน datasheet** ซึ่งแต่ละแหล่งให้ค่าต่างกัน
และ**ต่างกันตามชนิดก๊าซที่ต้องการวัด** (LPG, ควัน, มีเทน ให้เส้นโค้งคนละเส้น)

> ⚠️ **ค่า ppm ที่ได้จาก MQ-2 เป็นค่าประมาณหยาบมาก**
> เซนเซอร์ไม่สามารถแยกแยะชนิดก๊าซได้ — มันตอบสนองต่อก๊าซติดไฟทุกชนิดรวมกัน
> การรายงานเป็นตัวเลข "ppm" อาจทำให้เข้าใจผิดว่าแม่นกว่าความเป็นจริง
>
> **แนะนำ:** แสดงเป็น **ratio (Rs/R0)** หรือระดับเชิงคุณภาพ (ดี/ปานกลาง/แย่) แทนตัวเลข ppm
> จะซื่อสัตย์ต่อข้อมูลมากกว่า

**ค่าคงที่ทุกตัว** (`R_L`, `R0`, `a`, `b`, PGA, อัตราส่วน divider) **ต้องอยู่ในไฟล์ config**

## 6. การ calibrate

รายละเอียดเต็มอยู่ใน [04-calibration.md](../04-calibration.md#mq-2-ถ้าใช้) — สรุป:

### ขั้นที่ 1: Burn-in (ทำครั้งเดียวตอนซื้อมาใหม่)

จ่ายไฟให้เซนเซอร์**ต่อเนื่อง 24–48 ชั่วโมง** ก่อนใช้งานจริง
ระหว่างนี้ค่าจะเปลี่ยนตลอด — เป็นเรื่องปกติ ห้ามพยายาม calibrate ในช่วงนี้

### ขั้นที่ 2: หาค่า R0 (ความต้านทานในอากาศบริสุทธิ์)

```
1. วางเซนเซอร์ในอากาศสะอาด (นอกอาคาร หรือห้องที่ระบายอากาศดี ไม่มีควัน)
2. เปิดเครื่องทิ้งไว้ ≥ 20 นาที ให้ฮีตเตอร์เข้าที่
3. อ่านค่า Rs หลาย ๆ ครั้ง (เช่น 100 ครั้ง) แล้วหาค่าเฉลี่ย
4. R0 = Rs_เฉลี่ย / ratio_อากาศสะอาด        (ค่า ratio ในอากาศสะอาดราว 9.8 ตาม datasheet)
5. บันทึก R0 ลงไฟล์  calibration/mq2_r0.json
```

### ขั้นที่ 3: Warm-up ทุกครั้งที่บูต

รอ **3 นาที** หลังจ่ายไฟก่อนเชื่อค่า — ระหว่างนี้ให้ส่ง `null` ไม่ใช่ส่งค่าที่อ่านได้

### ต้อง calibrate ใหม่เมื่อไหร่

- ทุก 6 เดือน (เซนเซอร์ drift ตามอายุ)
- หลังย้ายตำแหน่งติดตั้ง
- หลังไฟดับนานกว่า 24 ชั่วโมง
- เมื่อค่าดูไม่สมเหตุสมผลอย่างชัดเจน

## 7. ข้อจำกัดที่ต้องรู้

| ข้อจำกัด | ผลกระทบ | ทางบรรเทา |
|---|---|---|
| **แยกชนิดก๊าซไม่ได้** | ควันบุหรี่กับแก๊สรั่วให้ค่าใกล้เคียงกัน | ใช้ร่วมกับ PMS7003 (ควันมีอนุภาค แก๊สไม่มี) |
| **ไวต่ออุณหภูมิและความชื้น** | ค่าเปลี่ยนตามสภาพอากาศ | ชดเชยด้วย T/RH จาก SCD40 (ซับซ้อน · ผลลัพธ์จำกัด) |
| **ฮีตเตอร์ร้อนตลอดเวลา** | เพิ่มความร้อนในกล่อง กระทบ SCD40 | วางแยกจากเซนเซอร์อื่น · ระบายอากาศดี |
| **อายุสั้น (~2 ปี)** | ค่า drift เรื่อย ๆ | calibrate ใหม่ทุก 6 เดือน · เปลี่ยนตัวเมื่อครบอายุ |
| **ไม่มีการรับรองความปลอดภัย** | ไม่ควรใช้เป็นระบบเตือนแก๊สรั่วหลัก | ติดตั้งเครื่องตรวจแก๊สที่ได้มาตรฐานเพิ่ม |
| **กินไฟ 150 mA ตลอดเวลา** | ~0.75W ต่อเนื่อง | — |

# ENV//MONITOR

**ระบบเฝ้าระวังสภาพแวดล้อมภายในอาคารและประเมินความจดจ่อด้วยเทคโนโลยี AIoT**

*An AIoT System for Indoor Environmental Monitoring and Attention Assessment*

---

## 1. ที่มาและความสำคัญ

การเรียนและการทำงานส่วนใหญ่เกิดขึ้น**ภายในอาคาร** ซึ่งเป็นพื้นที่ปิดที่สภาพแวดล้อมเบี่ยงเบนจาก
ธรรมชาติได้มาก — คาร์บอนไดออกไซด์สะสมจากลมหายใจ อุณหภูมิถูกควบคุมด้วยเครื่องปรับอากาศ
ฝุ่นละอองลอดเข้ามาจากภายนอก และเสียงรบกวนจากคนรอบข้าง

งานวิจัยในช่วงสองทศวรรษที่ผ่านมาแสดงให้เห็นว่าปัจจัยเหล่านี้**ไม่ได้ส่งผลแค่ความสบาย** แต่กระทบถึง
สมรรถนะการคิดและความสามารถในการจดจ่ออย่างวัดได้ อย่างไรก็ตาม งานวิจัยส่วนใหญ่**ศึกษาทีละปัจจัย
ในห้องปฏิบัติการ** ขณะที่สภาพจริงปัจจัยเหล่านี้เกิดขึ้นพร้อมกัน

## 2. แนวคิดของระบบ

โครงงานนี้จึงสร้างระบบที่วัดปัจจัยแวดล้อม **หลายตัวพร้อมกันแบบต่อเนื่อง** ควบคู่กับ
**ตัวชี้วัดพฤติกรรมความจดจ่อจากกล้อง** เพื่อให้เห็นความสัมพันธ์ในสภาพการใช้งานจริง
แล้วแปลผลให้ผู้ใช้ที่ไม่ใช่ผู้เชี่ยวชาญอ่านเข้าใจได้ด้วยปัญญาประดิษฐ์

จุดที่ต่างจากเครื่องวัดอากาศทั่วไปคือ ระบบไม่ได้ตอบแค่ *"อากาศตอนนี้เป็นอย่างไร"*
แต่ตอบว่า ***"ห้องนี้กำลังส่งผลกับคนที่อยู่ในนั้นอย่างไร"***

> ที่มาของเกณฑ์เตือนทุกค่า พร้อมรายการอ้างอิง 16 รายการ อยู่ใน
> [`docs/devices/research-basis.md`](docs/devices/research-basis.md) — ใช้เป็นบทที่ 2 ของเล่มรายงาน

## 3. สถาปัตยกรรม

```
  ┌──────────── อุปกรณ์ตรวจวัด ────────────┐
  │  ESP32-S3  (esp32s3-station-01)        │
  │    SCD40   CO₂ / อุณหภูมิ / ความชื้น    │
  │    SGP30   TVOC / eCO₂                 │        ┌─────────────────┐
  │    BH1750  ความสว่าง (lux)              │───────▶│  POST           │
  │    PMS7003 PM1 / PM2.5 / PM10          │  HTTPS │  /api/ingest    │
  ├────────────────────────────────────────┤        └────────┬────────┘
  │  Raspberry Pi + กล้อง (pi-vision)       │                 │
  │    จำนวนคน · การหันหน้า · การขยับ       │─────────────────┤
  └────────────────────────────────────────┘                 ▼
                                                    ┌─────────────────┐
                                                    │    Supabase     │
                                                    │  environment    │
                                                    │  focus          │
                                                    └────────┬────────┘
                                                             ▼
                                              ┌──────────────────────────┐
                                              │  Next.js (Vercel)        │
                                              │  แดชบอร์ด · คะแนนห้อง     │
                                              │  · ผู้ช่วย AI             │
                                              └──────────────────────────┘
```

ระบบแบ่งเป็นสี่ส่วนที่ทำงานแยกกันได้ ต่อกันด้วยสัญญาข้อมูลเดียว (`POST /api/ingest`)

| ส่วน | หน้าที่ | เทคโนโลยี |
|---|---|---|
| **สถานีตรวจวัด** | อ่านเซนเซอร์ตามรอบของแต่ละตัว แล้วส่ง JSON ขึ้นเว็บ | ESP32-S3 (Arduino C++) |
| **กล้องวัดความจดจ่อ** | ประมวลผลภาพ *ในเครื่อง* ส่งออกเฉพาะตัวเลขสรุป ไม่ส่งภาพ | Raspberry Pi · Python · MediaPipe |
| **ฐานข้อมูล** | เก็บอนุกรมเวลาของทั้งสองแหล่ง | Supabase (PostgreSQL) |
| **เว็บแดชบอร์ด** | แสดงผล · ให้คะแนน · สรุปด้วย AI | Next.js · React · Chart.js |

## 4. สิ่งที่วัด

| ค่า | เซนเซอร์ | หน่วย |
|---|---|---|
| อุณหภูมิ · ความชื้น | SCD40 | °C · %RH |
| คาร์บอนไดออกไซด์ | SCD40 | ppm |
| eCO₂ · TVOC | SGP30 | ppm · ppb |
| ฝุ่นละออง PM1 / PM2.5 / PM10 | PMS7003 | µg/m³ |
| ความสว่าง | BH1750 | lux |

ทุกค่าถูกตัดสินระดับตามเกณฑ์ใน [`config/sensors.js`](config/sensors.js) แล้วหักคะแนนรวมเป็น
**คะแนนสุขภาพห้อง 0–100**

เกณฑ์ฝุ่นตัดสินจาก**ค่าเฉลี่ยย้อนหลัง** ไม่ใช่ค่าวินาทีเดียว เพราะมาตรฐานฝุ่นเป็นค่าเฉลี่ยรายวัน —
ฝุ่นหนึ่งนาทีจึงไม่ควรพลิกสถานะทั้งห้อง

## 5. หน้าจอ

| หน้า | เนื้อหา |
|---|---|
| **สภาพแวดล้อม** | ค่าปัจจุบันทุกตัวเป็นการ์ดพร้อมกราฟย่อ · กราฟย้อนหลังเต็ม · มาตร AQI · ตารางสถิติ min/avg/max · คะแนนห้องพร้อมบทสรุปจาก AI |
| **การจดจ่อ** | ข้อมูลจากกล้อง — จำนวนคนในห้อง การหันหน้า และการขยับ |
| **ความปลอดภัยและสุขภาพ** | ความเสี่ยงโรคที่มาจากสภาพแวดล้อม · ระดับน้ำจากโครงการ StreeFlood · ข้อมูลราชการ (กรมอุตุนิยมวิทยา · ThaiWater · กรมชลประทาน) |

รองรับสองภาษา (ไทย/อังกฤษ) และธีมสว่าง/มืด

## 6. ปัญญาประดิษฐ์

ระบบเรียกผู้ให้บริการตามลำดับที่ตั้งไว้ จนกว่าจะมีตัวใดตอบ ถ้าล้มทั้งหมดจะตกไปที่**กลไกกฎในเครื่อง**
ซึ่งตอบได้เสมอ — แดชบอร์ดจึงไม่เคยค้างรอ AI

| ผู้ให้บริการ | ทำงานที่ไหน |
|---|---|
| เครื่องตัวเอง (llama.cpp · LM Studio · Ollama) | เครื่อง/เครือข่ายของผู้ใช้ |
| Google Gemini | คลาวด์ |
| WebLLM | ในเบราว์เซอร์ของผู้ใช้เอง ผ่าน WebGPU |

ผู้ช่วยได้รับ **เครื่องมือ** สำหรับไปอ่านข้อมูลเอง (เซนเซอร์ · ประวัติ · ระดับน้ำ · ความเสี่ยงโรค ·
ข้อมูลกล้อง · ค้นเว็บ) แทนการยัดข้อมูลทั้งก้อนลงใน prompt

> **ข้อมูลจากกล้องถูกกันไว้เป็นพิเศษ** — มีรายการกำหนดว่าผู้ให้บริการใดแตะข้อมูลนั้นได้
> ตัวที่ไม่อยู่ในรายการจะไม่ถูกเสนอเครื่องมือนี้เลย และถูกปฏิเสธถ้าเรียกมา
> การเพิ่มผู้ให้บริการบนคลาวด์ลงไปคือการส่งข้อมูลจากกล้องออกนอกเครือข่าย — นั่นคือทั้งหมดของการตัดสินใจนี้

## 9. การติดตั้ง

ต้องมี **Node.js 20** ขึ้นไป

```bash
npm install
cp .env.example .env.local     # ใส่ SUPABASE_URL และ SUPABASE_ANON_KEY
npm run dev                    # http://localhost:3000
```

จำเป็นแค่สองค่าแรกก็รันได้ ที่เหลือมีค่าตั้งต้นอยู่แล้ว — คำอธิบายทุกตัวอยู่ใน [`.env.example`](.env.example)

ระบบดีพลอยบน Vercel โดยคอมมิตที่เข้า `main` จะขึ้น production อัตโนมัติ
